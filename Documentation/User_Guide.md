# KidsLearn TV — Parent/Presenter User Guide

**Audience:** Children ages 4–8 with parent/caregiver supervision. All progress stays on the device. No child account or Wi-Fi connection is needed.

1. Launch on an Apple TV simulator. The Welcome screen shows **Start Learning** and **How to Play**. Select using the Siri Remote; Back dismisses overlays.
2. From Main Menu, choose **ABC World**, **Number Land**, **Colour Splash** or **Animal Kingdom**. The focused tile becomes more prominent.
3. Each world has five short lessons. Use **Hear Again** for spoken pronunciation, **Next** to continue or **Previous** to revisit. The last lesson shows **Finish Lesson**, which saves completion. Captions remain visible even without audio.
4. Select **Try a Quiz** after lessons or **Play Mixed Quiz** from Main Menu. Each five-question round has three selectable options. The first chosen option is locked in, then a kind feedback screen explains the answer.
5. If Exit Quiz is selected, a confirmation warns that an unfinished round is not saved.
6. Choose **Two-Player Challenge** for a shared-family game. Player 1 answers five questions, then Player 2 answers those same questions, each with independent scores. The results page announces a winner or tie.
7. **My Rewards** lists earned stars, completed lessons, quizzes played and five unlockable badges. Locked rewards encourage more play. Reset Progress clears all stored accomplishments only after confirmation.
8. To leave a screen, use the remote Back key; no tapping, keyboard or external game controller is required.

**Learning safety:** Gentle error messages avoid harsh feedback. All lessons and questions are for introductory educational play and should be checked by parents/educators for the child's needs. Animal audio is **spoken descriptive text**, not actual recorded animal calls.
